# ByteBites Reference File

## About This Project
You are building the backend logic for a campus food ordering app called ByteBites
using Python classes and simple algorithms.

## Project Scope
Do not add authentication logic, a database layer, or any features not described 
in the spec.

## Behavioral Instructions
- Only use the 4 classes: Customer, FoodItem, Menu, Transaction. Don't add new classes.
- Only include attributes and methods the spec explicitly asks for. If it's not in the
  feature request, leave it out (no remove methods, no IDs, no extra fields).
- The only extras allowed are what the tinker steps need: sorting items, filtering by
  category, and computing an order total.
- Don't store values that can be calculated. Compute the total cost instead of saving it.
- Keep it simple. Plain Python classes, no inheritance, no design patterns, no error
  handling beyond what's needed.
- When suggesting changes, work on one class at a time and explain why each change is needed.
